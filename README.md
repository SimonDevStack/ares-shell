## Ares Shell, a lightweight, modern, GPU-accelerated desktop shell.

 Ares Shell aims to be a lightweight and performant alternative to Quickshell and other resource-heavy desktop shells.

The project focuses on maximizing GPU acceleration and optimizing rendering performance to deliver a smooth, responsive desktop experience.

## Development Status

Ares Shell is in very early development.

We have no API nor particular architecture chosen yet
